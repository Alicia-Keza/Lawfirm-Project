# Rutabanks Notary & Legal Services – Website

Website for **Rutabanks Notary and Legal Services Ltd**, a registered notarial and legal services firm in Kigali, Rwanda.

> *"Precision in Law. Trust in Service."*

## Pages

| Page | Description |
|---|---|
| `index.html` | Home: hero, key stats, services preview, why choose us |
| `about.html` | Firm background, credentials, mission, vision and core values |
| `services.html` | Notarial, legal and specialized services |
| `contact.html` | Contact details, office hours, contact form and appointment booking |
| `disclaimer.html` | Legal disclaimer |

## Tech stack

- HTML5, CSS3 and vanilla JavaScript
- Google Fonts: Playfair Display and Open Sans

## Project structure

```
├── index.html
├── about.html
├── services.html
├── contact.html
├── disclaimer.html
├── css/styles.css   # design system and all page styles
└── js/main.js       # navigation, animations and form handling
```

## Running locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension for automatic reloads.
